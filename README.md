# Skimming to Seeing

A browser-based reading experience. Open `index.html` in a browser or publish the repository with GitHub Pages.

## Features

- Account creation and sign-in, including a sample reader profile
- Life of Pi chapter 3 reading timer with pause, continue, and end-session controls
- Chapter-complete action that plays an uploaded animation video
- XP rewards for reading, with themes, backgrounds, and avatars to unlock or purchase
- Preset and uploaded profile pictures
- Additional books in the library

The chapter text and animation are not included. Readers use their own copy of the book, and the chapter animation can be selected in the reading room.

Accounts, preferences, and reading progress are saved in the current browser. Use server-side authentication and storage before handling real accounts or personal data.
